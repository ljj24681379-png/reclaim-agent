# 归仓 Reclaim · 可交互 MVP

这是一个可离线运行的产品原型，用来证明主动式个人权益 Agent 的最小完整闭环：

1. 用户提供或授权个人记录；
2. Agent 按可核验规则发现候选权益；
3. 通过预期净价值（EV）决定是否主动打扰；
4. 展示依据、证据缺口与不确定性；
5. 生成可审计行动包；
6. 在用户确认授权后才进入“待发送”状态。

## 运行

直接用浏览器打开 `index.html`。无需安装依赖，无需网络。

## 真实边界

- 原型不读取真实邮箱、账单、保单或航旅账户。
- 原型不向任何外部机构发送材料。
- 成功率是用于说明产品机制的先验参数，不是真实业务数据。
- 法规或监管义务不会被自动表述为用户必然获得退款或赔付的权利。

## 主要文件

- `index.html`：产品界面与语义结构。
- `styles.css`：响应式视觉与交互状态。
- `app.js`：权益规则、EV 闸门、材料包、授权与审计逻辑。
